# 验证记录

环境：DSH 0.2.1-rc.5 · macOS · profile `desktop`。

## 功能

| 入口 | 观测 |
|---|---|
| 会话行「...」→ 智能重命名 | 弹窗立即出现，约 1.0 秒出候选；选中后弹窗关闭、侧栏标题同步 |
| 侧栏「更多」→ 智能重命名工作区 | 下拉切换工作区时候选各自刷新；改名后标题同步 |
| `/rename` | 回车后约 1.0 秒返回「已改为「X」。备选：A、B」，侧栏同步 |
| `/rename 突出工具链` | 参数作为偏好提示传给模型，仍由模型生成候选 |
| `rename_target` | 按 id 直接改名，不调用模型；会出现在 Agent 工具表里 |

## 边界

- **空会话**：提示「这个会话还没有内容，先聊几句再改名。」，不发模型请求，不显示红色错误
- **超时 / 报错**：4 秒超时、模型报错或 0 个候选都只提示「没想出更好的」，标题不变
- **Esc / 点遮罩**：只关闭弹窗，不改名
- **`$&` 注入**：`test/fill.test.mjs` 覆盖 `a $& b`、`$1`、`$'`、`$$`
- **来源校验**：无 `Origin`（curl）放行；错误端口、外域 Origin、错误 Host、`Origin: null` 均返回 403

## 单元测试

```sh
node --test test/*.test.mjs
# 8 passed
```

覆盖：占位符替换的 `$` 转义、名称空格规整、列表符号剥离、句子/超长/重复过滤、状态语过滤。

## 持久化

- 会话标题走 `session/title` 事件，存在会话文件里
- 工作区标题落在 `~/.dsh/storages/workspace.json`
- 自定义提示词存在 `~/.dsh/profiles/<profile>/dsh-smart-namer.prompts.json`

插件重载、页面刷新、重启 App 后均保持。

## 已知限制

- 候选以中文短名为主（≤12 个汉字，总计 ≤24 字）
- 一次只给 3 个候选，没有「再想想」
- 不做自动触发、批量改名、缓存
